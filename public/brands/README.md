# Official social logos

These assets are copied unchanged from the official brand downloads.

- `x-white.png`: `logo-white.png` from https://about.x.com/content/dam/about-twitter/x/brand-toolkit/x-logo.zip
  - Toolkit: https://about.x.com/en/who-we-are/brand-toolkit
  - Guidelines: https://about.x.com/content/dam/about-twitter/x/brand-toolkit/x-brand-guidelines.pdf
- `github-white.svg`: `GitHub Logos/SVG/GitHub_Invertocat_White.svg` from https://brand.github.com/GitHub_Logos.zip
  - Guidelines: https://brand.github.com/foundations/logo

Use only as links to the owner's profiles. Keep the original shapes and white color, and preserve clear space.
The profile links use transparent hit areas, as requested by the site owner. The 24px marks have
24px of surrounding padding (also exceeding GitHub's 25% clear-space guidance).
